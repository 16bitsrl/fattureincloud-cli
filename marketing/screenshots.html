CLI

Tutto quello che serve, in un colpo d'occhio

Basta lanciare fic: comandi principali e guida completa per le persone e per gli agenti AI.

$ fic
fic 1.2.0: command line client for the Fatture in Cloud API.

Status
  Signed in as Mario Rossi (mario@rossi-srl.it), default company: 12345

Get started
  fic auth:login              Sign in through the browser, read-only (or --token=TOKEN)
  fic auth:grant SCOPE        Add a permission when a command asks for it

Call the API
  fic api:list                Every API command with its HTTP method and path
  fic clients:search TEXT --company-id=ID
CLI

Permessi solo quando servono

Si parte in sola lettura. Se un comando deve scrivere, CLI ti dice quale permesso aggiungere.

$ fic api:create-issued-document --company-id=12345 --input="$(cat fattura.json)"
Missing permission: this command needs issued_documents.invoices:a.
Grant it with: fic auth:grant issued_documents.invoices:a
Approve it with the link and code it prints, then run this command again.

$ fic auth:grant issued_documents.invoices:a
To authorize fic with your Fatture in Cloud account, open:
  https://fattureincloud.it/connetti
and enter the code:
  LCPI-YYTX
